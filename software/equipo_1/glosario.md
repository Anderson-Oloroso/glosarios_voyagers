# Glosario software Team 1

| Término | Descripción |
|---|---|
| `OFFSET` | Cláusula de SQL que permite **saltar una cantidad determinada de filas** antes de comenzar a devolver los resultados de una consulta. Se utiliza comúnmente junto con `LIMIT` para paginar resultados. |
| `DETERMINISTIC` | Palabra clave utilizada en algunos sistemas de bases de datos para indicar que una función, dados los mismos valores de entrada, **siempre produce el mismo resultado**. Esto permite al sistema saber que la función no depende de valores externos o variables cambiantes. |
| `PSQL` | Interfaz de línea de comandos de **PostgreSQL** que permite conectarse a una base de datos y ejecutar consultas SQL, comandos administrativos y scripts directamente desde la terminal.                                                                                      |
